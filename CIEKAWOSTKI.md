# CIEKAWOSTKI — Witryna 0.3.0

- Sześć autentycznych zrzutów z dwóch etapów rozwoju: 0.6.3.5 i linii 0.7.x.
- Nowy kadr pokazuje lokalne rozpoznanie KDR w promieniu 40, 80, 160 lub 300 metrów — inną skalę niż operacyjna mapa powiatu.
- Widok 2D nie służy do ręcznego sterowania strażakami: prezentuje działania i informacje z symulacji.
- Galeria i pełnoekranowy podgląd korzystają z natywnego JavaScript i HTML, bez dodatkowych zależności.
- IBM Plex Sans i Inter mają bardziej neutralny, produktowy charakter; techniczne etykiety nadal wykorzystują IBM Plex Mono.
- Dzięki ścieżkom względnym witryna pozostaje zgodna z GitHub Pages pod `/SKKP/`.
